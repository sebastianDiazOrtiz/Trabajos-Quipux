1.¿Que es este proyecto?
Estes proyecto es un sistema de calificacion y edicion de notas para la universidad catolica de oriente su principal funcion es:
-Que los profesores pueden subir las notas y editarlas.
-Que los estudiantes puedan ver las notas que sube cada profesor.
En si el sistema es muy básico, principalmente para que tanto los profesores y los estudiantes no se pierdan al momento de ver las notas sus atributos principales son los siguientes
Tipos de datos.
Ciclos.
Validacion de datos.
